@@ 4 Confirm the policy and make the scoped repair
Prove which export rule explains the missing advertisement. Re-read the target,
then stage and review one change before committing it.

Start in WSL:
  make enter NODE=edge01.bob1.reefnet.test
@@ hint
Trace the BGP neighbor, peer-group, export-policy, prefix-set and action:
  info from running network-instance default protocols bgp
  info from running network-instance default protocols bgp group lagoon-v4
  info from running network-instance default protocols bgp group lagoon-v6
  info from running routing-policy
A group-level export policy overrides the instance policy. If the evidence
supports removing an override, re-read the configuration, then use candidate mode:
  enter candidate
  delete / network-instance default protocols bgp group <group-name> export-policy
  diff
Commit only if the diff shows that one intended deletion:
  commit now
To restore a committed change, set the original policy attachment, review diff
and commit. `discard now` only cancels uncommitted changes. Leave with quit.

Inside ReefNet Edge 01:

  enter candidate

  diff
Commit only if the diff contains this deletion and no unrelated edits:
  commit now
  info from running network-instance default protocols bgp group lagoon-v4
  quit
Conditional rollback, only if the repair causes an unintended regression:
WSL repository:
  make enter NODE=edge01.bob1.reefnet.test
Inside ReefNet Edge 01:
  enter candidate
  set / network-instance default protocols bgp group lagoon-v4 export-policy [ BLOCK-CUSTOMER-V4 ]
  diff
After confirming that only the original attachment is restored:
  commit now
  quit
@@ solution
Neighbor 192.0.2.2 uses group lagoon-v4. The instance policy is EXPORT-BGP,
but the group overrides it with BLOCK-CUSTOMER-V4. That policy rejects
198.51.100.0/24. Removing only the group override restores inheritance from
EXPORT-BGP. Do not edit the shared policy. Continue to step 5 to prove recovery.
